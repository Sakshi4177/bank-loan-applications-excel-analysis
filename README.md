## Bank Loan Applications Analysis – Excel Dashboard

## 📊 Project Overview

This project analyzes bank loan application data using Microsoft Excel to understand loan performance, customer behavior, funding, repayment, and risk patterns.
Workflow: Data Cleaning → Data Transformation → Pivot Tables → KPI Analysis → Dashboard → Business Insights

## 🎯 Business Objective

* The objective is to analyze loan application and performance data and answer questions such as:
* How many loan applications were received?
* What is the total funded loan amount?
* How much amount was received from borrowers?
* What percentage of loans are performing well vs. charged off?
* Which loan purposes have the highest number of applications?
* How does loan performance vary by credit grade?
* How do applications change month by month?
* Which loan terms are more common?
* How does interest rate vary by loan status?
* What factors may be associated with higher loan risk?

## 🧹 Data Cleaning & Preparation

* The dataset contains approximately 14.4K loan application records.
* Cleaning and transformation included:
* Checked duplicate records and duplicate IDs.
* Removed leading/trailing spaces from text fields.
* Handled missing employment-title values as Unknown.
* Converted Excel date serial numbers into readable dates.
* Formatted interest rate as a percentage.
* Formatted debt-to-income ratio (DTI) as a percentage.
* Standardized employment-length values for analysis.
* Reviewed unusual income values as potential outliers instead of deleting them automatically.

## 📈 Dashboard Analysis

1. Good Loan vs. Bad Loan
* Good Loans: Fully Paid + Current
* Bad Loans: Charged Off
* The dashboard shows approximately 84% Good Loans and 16% Bad Loans.

2. Loan Applications by Purpose
* Debt consolidation has the highest application volume, followed by credit card and other major purposes.
3. Monthly Loan Application Trend
* Application volume increases through the year, with December showing the highest monthly volume in the dashboard.
4. Interest Rate by Loan Status
* The dashboard compares average interest rates for Charged Off, Current, and Fully Paid loans. Charged-off loans show a higher average interest rate than fully paid loans in this dashboard.
5. Loan Term
* The dashboard compares 36-month and 60-month loans. 36-month loans represent the larger share.
6. Credit Grade
* Grades A to G are available through the dashboard filter and can be used for deeper risk analysis.


## 💡 Key Insights

* The portfolio contains approximately 14.4K loan applications.
* Around 84% of loans are classified as good loans, while approximately 16% are charged off.
* Debt consolidation is the largest loan-purpose category by application volume.
* December has the highest monthly application volume in the dashboard.
* Average interest rate is approximately 12.30%.
* Average DTI is approximately 13.35%.
* 36-month loans are more common than 60-month loans.
* Charged-off loans have a higher average interest rate than fully paid loans in the dashboard, suggesting a possible relationship between pricing and borrower risk.
* Credit grade is an important segmentation variable for deeper risk analysis.
